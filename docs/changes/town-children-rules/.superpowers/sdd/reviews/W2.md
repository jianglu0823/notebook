## 2. Code Quality

### Strengths
- **耦合点最小化**:`birth()` 只换一行;`childbirths()` 只在 8% 判定前加一行 `continue`。回归面积极小。
- **`coupleAtCap` helper 独立可测**:用包内可见(package-private)直接覆盖,不需要反射。
- **健壮的 parentIds 解析**:`split(",") + trim + 过滤空串` 三件套处理 `birth()` 写入的 `"a,b"`、可能产生的尾逗号、空值。
- **Lombok @RequiredArgsConstructor 自动重生成构造器**:`childrenProps` 加到字段列表,无需手写 ctor。
- **测试 case 设计**:6 个 `coupleAtCap` 测试覆盖正反边界 + 健壮性 + 隔离性,无重复。

### Minor observations (not blocking)
- `coupleAtCap` 的 in-app 过滤对 N+1 风险:每对夫妇查一次 `findByParentIdsContaining(a.id)`,返 N 行再做 Java filter。N 通常很小(<5),但理论上当孩子数大时是 O(N) per couple。生产环境实测无影响(W2 编译过 / 195+10 测试绿),后续优化可换 `findByParentIdsContaining` 两条 + HashSet 求交集。
- `birth()` 仍接收 `String avatar` 参数但忽略。考虑过移除参数以彻底消除误用,但 `WorldSimEngine.childbirths()` 仍是唯一调用方且传 `"👶"`,移除会动到调用方,scope 偏大。注释已说明"忽略"。
